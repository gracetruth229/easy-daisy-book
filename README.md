# ㈜공간네트웍스 재무관리시스템

엑셀로 쓰던 월별 회계보고를 그대로 옮긴 **웹 회계장부**입니다.
설치할 것도, 로그인할 것도 없습니다. 브라우저에서 열면 바로 씁니다.

## 무엇을 하나

| 화면 | 하는 일 |
|---|---|
| **전표 입력** | 거래를 줄로 적습니다. 차변 합계와 대변 합계가 같아야만 저장됩니다. 거래처는 등록해 둔 목록에서 골라 넣습니다. |
| **전표장** | 저장된 전표를 전표 단위로 묶어 보여주고, 전체 대차를 검증합니다. 전표는 **지워지지 않습니다.** |
| **거래처** | 거래처와 사업자등록번호를 관리합니다. 사업자번호 검증번호를 자동으로 확인합니다. |
| **집계표** | 계정별 차변·대변 합계와 잔액을 자동으로 냅니다. |
| **재무제표** | 재무상태표와 손익계산서를 만듭니다. 손익계산서는 **월별 칸이 나란히** 서고 맨 오른쪽에 누계가 붙습니다. 자산총계 = 부채·자본총계를 항상 확인합니다. |
| **계정과목** | 계정을 추가하거나 이름을 바꿉니다. 코드 앞 3자리가 더존 표준 계정과목코드입니다. |
| **내보내기** | 통합 엑셀(xlsx 5시트), CSV, 더존 일반전표 형식으로 받습니다. 백업·가져오기도 여기 있습니다. |

## 전표는 지워지지 않습니다

회계 기록은 지우거나 몰래 고치면 안 됩니다. 그래서 이렇게 만들었습니다.

- **삭제 기능이 없습니다.** 전표는 늘어나기만 합니다.
- 저장한 전표는 **잠깁니다.** 고치려면 「잠금 해제」를 한 번 더 눌러야 하고,
  고친 뒤에는 **몇 번 고쳤는지·언제 고쳤는지가 전표에 남습니다.**
- 거래 자체가 잘못됐다면 고치지 말고 **「역분개」**를 쓰세요.
  차변과 대변을 뒤집은 취소 전표가 새로 생기고, 원래 전표는 그대로 남습니다.
  원본에는 「취소됨」, 새 전표에는 「역분개」 표시가 붙습니다.

## 엑셀에서 달라진 점

- **대차가 안 맞으면 저장이 안 됩니다.** 양쪽 금액을 따로 적다가 어긋나는 일이 생기지 않습니다.
- **`#N/A`가 없습니다.** 계정은 목록에서만 고르므로 VLOOKUP이 깨질 일이 없습니다.
- **재무제표 행이 안 깨집니다.** 계정을 추가해도 BS·PL이 자동으로 따라옵니다.
- **거래처를 한 번만 등록하면 됩니다.** 전표에서 이름을 치면 목록이 뜨고,
  고르면 사업자등록번호가 자동으로 들어갑니다.
- **월별로 파일을 나누지 않아도 됩니다.** 왼쪽 위 기간 선택으로 전체와 월별을 오갑니다.
- **월별 손익계산서입니다.** 전표가 있는 달마다 칸이 하나씩 생기고
  (`6월 | 7월 | 누계`), 8월 전표를 넣으면 8월 칸이 저절로 붙습니다.
  6월 30일자 임차료가 6월에만 잡히고 7월에서는 빠지는 것처럼,
  어느 달의 실적인지가 한눈에 갈립니다.

## 자료는 어디에 저장되나

**여러분 브라우저 안에만** 저장됩니다 (localStorage). 서버로 올라가지 않고,
이 저장소에도 회계 자료는 들어 있지 않습니다.

그래서 두 가지를 기억해 주세요.

1. **브라우저 자료를 지우면 장부도 지워집니다.** 정기적으로
   `내보내기 → 백업 내려받기`로 JSON 파일을 받아 두세요.
2. **다른 기기·다른 브라우저에서는 비어 있습니다.** 백업 JSON을
   `내보내기 → 가져오기`로 불러오면 그대로 이어집니다.

## 시작하기

- 처음 열면 기본 계정과목 71개가 들어간 빈 장부가 뜹니다.
- 화면 색은 [공간복붙](https://ggcv.co.kr) 과 같은 코발트(`#0052ff`) 톤입니다.
- 쓰시던 자료가 있으면 `내보내기 → 가져오기 → 덮어쓰기`로 백업 JSON을 불러오세요.
- 없으면 `전표 입력`에서 바로 첫 전표를 쓰시면 됩니다.

## 계정과목 코드

7자리 코드의 **앞 3자리가 더존 표준 계정과목코드**입니다.

```
1030000 → 103 보통예금       2530000 → 253 미지급금
8190000 → 819 임차료         2570000 → 257 가수금
8310000 → 831 지급수수료     3310000 → 331 자본금
```

`내보내기 → 더존 일반전표 CSV`를 고르면 앞 3자리로 잘라서 나가고,
구분이 `3`(차변)·`4`(대변)로 붙습니다.

## 직접 돌려보기

파일 하나짜리라 받아서 열기만 하면 됩니다.

```bash
git clone https://github.com/<계정>/gongan-ledger.git
cd gongan-ledger
```

`index.html`을 브라우저로 열면 끝입니다. 빌드 도구도 서버도 필요 없습니다.
